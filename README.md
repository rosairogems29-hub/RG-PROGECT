# Rosairo Gems & Lapidary — Website Starter

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive desktop + mobile layout
- No build tools required

## Open locally
Double-click `index.html`, or use a simple local server such as VS Code Live Server.

## Where to update products
Open `js/app.js` and edit the `products` array.
Each product supports:
- name
- category
- subcategory
- carat
- origin
- treatment
- shape
- cut
- price
- image
- description

Replace `assets/hero-gem.svg` with your real image files when ready, then update the `image` path for each product.

## Categories / subcategories
Edit the `categories` array in `js/app.js`.

## News & events
Edit the `events` array in `js/app.js`. Add your exhibition photos/videos later.

## Gallery
Edit the `gallery` array in `js/app.js`.

## Social links
Replace the placeholder # links in `index.html` with the exact Facebook, Instagram and TikTok URLs.

## Important
This is the first static front-end build. It intentionally has no online checkout.
The catalogue flow is:
Browse -> View individual stone -> See specifications/media -> WhatsApp / Email enquiry.

For the next phase, a small admin/CMS + image storage + database can be added so you can add/edit gemstones, prices, photos, videos, categories and events without editing code.
