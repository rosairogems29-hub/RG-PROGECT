# Rosairo Gems & Lapidary — Website

Static HTML/CSS/JS website prepared for Netlify or GitHub Pages.

## Main files
- index.html — complete website
- styles.css — responsive design
- script.js — hero slider, collection tabs, mobile menu
- admin.html — local catalogue helper
- assets/ — supplied website images

## Hero slider
The Home hero starts with the supplied blue sapphire image, then moves through the other supplied images in upload order. The visual transition is 1.5 seconds and the slider loops continuously. Its current position/time is saved in localStorage so returning to Home does not reset the sequence.

## Mobile Collection tabs
Collection tabs are horizontally scrollable on mobile only.

## Deployment
Upload the entire folder to Netlify, or upload its contents to a GitHub Pages repository. No build command is required.

## Important contact placeholders
The WhatsApp URL and email are placeholders and should be replaced with the business's final contact details before publishing.
