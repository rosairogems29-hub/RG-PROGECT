# Website update

This version updates the original RG-PROGECT project without replacing its design.

- Home hero is now a full background slideshow using the supplied images, starting with the blue sapphire.
- Hero images loop continuously; the current image/timing is saved in localStorage so returning to Home does not reset the sequence.
- The Collection image is the supplied pink gemstone heart image.
- Collection labels/images updated for Sapphire Single Stones, Calibrated Sapphire and Jewellery.
- Mobile Collection category links are horizontally scrollable.
- Original pages, admin system, gemstone data and existing styling are retained.
